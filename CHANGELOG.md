# История изменений

## 1.1 — 13 октября 2026

### Исправлено

- **Слова с толкованием внутри шаблона.** В Викисловаре само толкование иногда
  оформлено шаблоном `{{===|слово}}` (частая ситуация для разговорной лексики).
  Приложение показывало такие слова пустыми или только с пометами вида
  «(разг.), (груб.).» — теперь толкование читается.
- **Формы слов.** Статьи-формы («идёт», «думает», «иду», «стола» и подобные)
  не показывали ничего: разделы «форма глагола» / «форма существительного»
  (`{{Форма-гл}}`, `{{Форма-сущ}}`) не разбирались. Теперь такие слова
  показываются с описанием: время, наклонение, лицо, род, число, падеж,
  а также помета и значение формы.
- **Заголовки языковых разделов с параметрами** (`= {{-ru-|nocat}} =`)
  не распознавались — статья считалась «пустой».
- **Сокращения-пометы** (`{{мол.}}`, `{{несов.}}`, `{{истор.}}`, `{{техн.жарг.}}`
  и другие) и служебные символы (`{{-}}`, `{{--}}`, `{{итп}}`) терялись,
  из-за чего слова в определении слипались («Свободысколько возможно»).
- **Термин в шаблонах** `{{t:=|термин|пояснение}}` не показывался — теперь
  выводится как «термин — пояснение».
- **Определения из одних помет** больше не выводятся: если после удаления
  «(разг.)», «(груб.)» и знаков препинания не осталось текста, строка
  считается пустой.

### Изменено

- Часть речи определяется дополнительно по коротким именам шаблонов
  (`{{adv ru сравн}}`, `{{predic}}`, `{{part}}`, `{{intro}}`) и по заголовку
  раздела («(наречие I)»).
- Кэш результатов версионирован: после обновления старые записи, сделанные
  прежней версией разбора, сбрасываются автоматически.
- Добавлены автотесты разбора вики-разметки: `python -m unittest discover -s tests`
  (16 проверок, интернет не нужен).

### Проверено

- 18 русских слов разбираются без пустых и обрезанных значений
  (включая «дрочила», «идёт», «стола», «лучше», «пальто», «кошка», «коса»).
- 39 проверок интерфейса — все пройдены.

## 1.0 — 13 октября 2026

- Первый выпуск: всплывающее окно поверх всех окон по `Ctrl+Space`, русский
  Викисловарь и `dictionaryapi.dev`, исправление опечаток через Яндекс.Спellер,
  кэш результатов, сборка автономного `.exe`.
